## Long Description
Troupe helps you find the right collaborators for your next project.

Build a profile with your skills, interests, and project experience, discover people with similar goals, send requests, and start chatting when you match.

### Key features
- Skill-based discovery feed
- Like, match, and intro message flow
- Real-time chat with matched users
- Detailed profiles with projects and experience
- Optional location sharing (city/country)
- Push notifications for requests and messages
- Account controls for block/report/delete

### Who it’s for
- Builders looking for teammates
- Students seeking project collaborators
- Creators and developers forming side-project teams

### Privacy and control
- You control what profile information is shared.
- Location sharing is optional.
- You can block/report users and delete your account.
